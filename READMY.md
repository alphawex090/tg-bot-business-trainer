# 🤖 Telegram-бот для сбора заявок (Бизнес-тренер)

Асинхронный Telegram-бот, разработанный для автоматизации сбора заявок от клиентов бизнес-тренера. Бот собирает контактные данные, сохраняет их в базу данных и предоставляет администратору удобную панель управления.

## 🎯 Бизнес-задача
Автоматизировать первичный сбор лидов (заявок) от клиентов, избавив тренера от ручной работы. Бот собирает анкету, уведомляет администратора и позволяет выгружать базу клиентов в Excel для дальнейшей работы.

## 🛠 Стек технологий
* **Python 3.10+**
* **aiogram 3.x** — современный асинхронный фреймворк для Telegram-ботов.
* **SQLAlchemy 2.0 (async) + SQLite** — работа с базой данных.
* **CSV / io** — генерация файлов на лету.
* **python-dotenv** — безопасное хранение токенов.

## ✨ Основной функционал
### Для пользователя:
* Удобная пошаговая анкета (FSM): Имя -> Телефон -> Описание запроса.
* Валидация данных и понятные ответы бота.

### Для администратора (тренера):
* Мгновенные уведомления о новых заявках.
* **Админ-панель** с инлайн-кнопками.
* Просмотр последних 5 заявок.
* Статистика (всего заявок / заявок за сегодня).
* **Экспорт всех заявок в CSV** (готовый файл для Excel с правильной кодировкой).
* Функция массовой рассылки (`/broadcast`) с автоочисткой заблокировавших бота пользователей.
